# Tycoon Gaming Wiki (user app)

Archived copy of the Tycoon Gaming Wiki (Feb 2026 snapshot): 629 pages in 23 languages. No images.

## Features
Draggable, resizable window (add ?full=1 to the URL for a full-screen page) (minimise, maximise, transparency, pin, close), language dropdown, instant search (`/` to focus), A–Z index, topics, on-page contents, back/forward, light/dark theme, text size.
- Click outside the window to hide it (F1 brings it back), keep it on screen, or do nothing: choose in the window settings (gear icon).
