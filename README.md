# Tycoon Gaming Wiki (user app)

Archived copy of the Tycoon Gaming Wiki (Feb 2026 snapshot): 629 pages in 23 languages. No images.

**Open it:** https://hellogoobie.github.io/Transport-Tycoon-Wiki/#/EN/home

- In a browser: open the link above.
- In game: press **F1**, choose to load an Application URL, and paste the link.

## Features
Draggable, resizable window (add `?full=1` to the URL for a full-screen page) (minimise, maximise, transparency, pin, close), language dropdown, instant search (`/` to focus), A–Z index, topics, on-page contents, back/forward, light/dark theme, text size.
- Click outside the window to hide it (F1 brings it back), keep it on screen, or do nothing: choose in the window settings (gear icon).

## Help update the wiki

Every page is one file in [`content/`](content), so anyone can fix or add something with a pull request. See **[CONTRIBUTING.md](CONTRIBUTING.md)**. For example, the staff list is [`content/EN/Other/Credits.html`](content/EN/Other/Credits.html).

`data/` is generated from `content/` by `tools/build.py` (automatically, after a PR is merged). Don't edit it by hand.
