Event Scripts

Event Scripts are small independent resources that contain one server and one client script.

They can be added to the server by administrators and enabled/disabled by staff.

The purpose of Event Scripts is to allow custom stuff for events that the community can contribute to.

Example stuff can be: 

- Custom minigame stuff, like weapon spawning and score counters.
- Tiny features like flashing the headlights when honking.
- Toggleable Noclip for all players

There's really no limit to what the scripts can do.

Source Code for a couple of the scripts we already made: Outline Player Vehicles Flash Headlights When Honking Allow /nc (Noclip) For Everyone

These scripts are essentially just snippets of client and or server code that do certain things.

If you wish to contribute with cool small things you've made, contact staff!
