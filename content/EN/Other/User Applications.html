--- title: User Applications ---

User Applications are web applications loaded directly into the game client.

Note: This application will get access to game and account information, only load applications you trust.

By pressing F1 and entering a URL into the input field, you will load the web application at the specified URL inside your game client.

The game will provide details about you (the player), your game (what you're doing) and your account (progress, job, account information) directly to the web application.

This web application will be able to display information on your screen, and it can have an interactable interface accessible using the F1 key.

There are 4 optional keys you can set in the FiveM section of the Keyboard Bindings in the game settings:

Square, Triangle, Circle and Cross. These 4 buttons may interact with the web application, if it supports their use.

For developers who want to create user applications, see http://server.tycoon.community:30125/status/config/user-apps or for a html rendered version see https://ttycoon.eu/userapps/docs

For users who want to find a list of public user applications, see the user-applications channel (Discord)
