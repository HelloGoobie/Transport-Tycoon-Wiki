Parâmetros do mapa "ao vivo" (Live Map)

É possível visualizar o mapa em tempo real em todos os servidores do Tycoon. Instruções abaixo.

Você pode ajustar os seguintes parâmetros:

highlight: Um ID que queira acompanhar, se utilizado, esta será a única pessoa que verá no mapa.

server: O ID do server do qual quer ver os players, este geralmente é o número do servidor (exceto nos servidores 1 e 6, cujo ID é 0)Isto parece não funcionar corretamente, siga os exemplos a seguir.

vehicle: O tipo de veículo que você quer ver, pode ser foot (a pé), land (terrestre),boat (barco),helicopter (helicóptero), plane (avião) ou train (trens). Padrão: all (todos)

class: A classe de veículo que quer visualizar, veja a lista de veículos em FiveM Native Reference. Padrão: all (todos)

job: Mostra apenas jogadores com o emprego especificado (pode ser apenas parte do nome do emprego), recebe o ID interno do grupo do emprego. Padrão: all

lines: Desenha padrões em linhas, mude para no (não) para desabilitar. Padrão: yes (sim)

clamping: Previne "clipping" (andar além das bordas do mapa), mude para no (não) para desabilitar. Padrão: yes (sim)

localhost: Mostra apenas o server que você requer o mapa, mude para no (não) para não mostrar todos os servidores do Tycoon. Padrão: yes (sim) localhost não funciona corretamente com o servidor 6 através do A, o que é o motivo para que não possa ver todos de uma vez.

color: O modo de cores dos ícones do mapa pode ser player (jogador), server (servidor), none (nenhum). Padrão: player (jogador)
