Parâmeteros Live Map

É possível ver um livemap de todos os servidores Transport Tycoon. As Instruções podem ser lidas abaixo.

Pode especificar os seguintes parâmetros:

highlight: O Id de alguém que quer seguir, se for especificado irá ser a única pessoa que vê.

server: O id da porta do servidor do qual quer ver os jogadores. Isto não parece funcionar corretamente refira-se aos exemplos abaixo.

vehicle: O tipo de veículo que quer ver, pode ser foot, land, boat, helicopter, plane, train. Por defeito: todos

class: A classe do veículo quer quer mostrar, o índice de classes, pode ser encontrado em FiveM Native Reference. Por defeito: todos

job: Mostra apenas jogadores com o trabalho específico (também pode ser parte do nome do trabalho), leva o id do grupo interno do trabalho. Por defeito: todos

lines: Desenhar linhas de caminho, defina como no para desativar. Por defeito: ativada

clamping: Para evitar o recorte fora das bordas do mapa defina como no para desativar. Por defeito: ativada

localhost: Apenas mostra o servidor de que está a pedir o mapa, defina como no para mostrar todos os servidores. Default: ativada localhost não funciona corretamente com o 6 junto com o A e é por isso que não consegue ver todos de uma vez.

color: O modo de cor para os ícones de mapa podem ser player, server, none. Por defeito: player
