Параметры Онлайн-Карты

Есть возможность увидеть Онлайн-Карту всех текущих серверов Transport Tycoon. Инструкция указана в Примерах.

Ниже указаны специфичные параметры:

highlight: ID, которое Вы хотите отследить, если под Ваш интерес попал определённый игрок и Вы хотите видеть только его.

server: ID-порт сервера, на котором Вы хотите увидеть игроков; этот номер сервера в большинстве случаев (исключение: сервер 1 и 6) ID-порт - 0. Это не работает корректно, потому используйте примеры ниже.

vehicle: Определённый тип ТС, который хотите видеть; может быть foot, land, boat, helicopter, plane, train. По умолчанию: all

class: Определённый класс ТС, который хотите видеть, используя индекс класса, который можно найти в FiveM Native Reference. По умолчанию: all

job: Показывает игроков только с определённой профессией (также может быть и часть названия профессии), используя ID профессии. По умолчанию: all

lines: Очерчивает линию пути, укажите no для отключения. По умолчанию: "yes"

clamping: Предотвращает "выход" за границы карты, укажите no, что-бы отключить. По умолчанию: "yes"

localhost: Показывает только сервер, на который Вы сослались, укажите no, что-бы видеть все сервера Tycoon. По умолчанию: yes localhost не работает корректно с сервером 6 через A, из-за чего Вы не сможете увидеть всё здесь сразу.

color: Цветовой режим для иконок карты, может быть player, server, none. По умолчанию: "player"
